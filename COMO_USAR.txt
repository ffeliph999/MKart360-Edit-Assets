==========================================================================
 MKart360 Edit Assets - COMO USAR
==========================================================================

Siga os passos na ordem. Os comandos ficam numa linha própria, recuados:
copie a linha inteira e cole no PowerShell, dentro da pasta
MKart360-Edit-Assets\mk64-master (exceto onde indicado).

Para explicações detalhadas, veja o LEIA-ME.md (em português) ou o
README.md (em inglês).


--------------------------------------------------------------------------
 PASSO 1 - INSTALE O VISUAL STUDIO 2010 E O XDK DO XBOX 360
--------------------------------------------------------------------------

Eles são necessários para compilar o jogo para o Xbox 360.


--------------------------------------------------------------------------
 PASSO 2 - ADICIONE SUA ROM
--------------------------------------------------------------------------

Renomeie sua ROM para baserom.br.z64 e coloque-a em:

    MKart360-Edit-Assets\mk64-master\baserom.br.z64

Exemplo: se a sua ROM se chama "Mario Kart 64 (USA).z64", renomeie-a
para baserom.br.z64.

O jogo aceita a versão americana (USA) e a brasileira, e identifica qual
é pelo conteúdo, não pelo nome. A ROM precisa estar no formato .z64.


--------------------------------------------------------------------------
 PASSO 3 - INSTALE O PYTHON (só uma vez)
--------------------------------------------------------------------------

    winget install Python.Python.3

Feche e abra o PowerShell de novo e confira a instalação:

    py --version

Se aparecer algo como "Python 3.13.x", está tudo certo.


--------------------------------------------------------------------------
 PASSO 4 - INSTALE O PILLOW (só uma vez)
--------------------------------------------------------------------------

    pip install pillow


--------------------------------------------------------------------------
 PASSO 5 - CONFIGURE AS FERRAMENTAS DE ASSETS
--------------------------------------------------------------------------

    powershell -ExecutionPolicy Bypass -File ".\xbox360\setup_windows_asset_tools.ps1" -SkipTorch

Prepara as ferramentas para trabalhar com os assets e as texturas.


--------------------------------------------------------------------------
 PASSO 6 - PREPARE A ROM E OS ASSETS
--------------------------------------------------------------------------

    py .\PUBLIC_PREPARE_MK64_ASSETS.py


--------------------------------------------------------------------------
 PASSO 7 - EXTRAIA AS TEXTURAS
--------------------------------------------------------------------------

    py .\EXTRACT_MK64_TEXTURES.py

As texturas vão para a pasta extracted_textures, e os manifestos (.json)
são preparados automaticamente. Não é preciso copiar nada da pasta
manifest_runtime.

Se você rodar de novo, as texturas que já editou não são sobrescritas.


--------------------------------------------------------------------------
 PASSO 8 - EDITE AS TEXTURAS
--------------------------------------------------------------------------

Abra os PNGs em extracted_textures e edite os que quiser: redesenhe,
substitua ou aumente a resolução (por exemplo, de 64x64 para 128x128).

  * Não renomeie os arquivos nem mude a estrutura das pastas: o nome e o
    caminho ligam cada PNG à textura original do jogo.

  * Depois de colocar ou alterar uma textura HD de fundo de menu, rode de
    novo o passo 7. O extrator gera as versões coloridas dos fundos.


--------------------------------------------------------------------------
 LIMITES DE MEMÓRIA (leia antes do passo 9)
--------------------------------------------------------------------------

O Xbox 360 tem 512 MB de memória, compartilhada com o jogo. Tamanho
aproximado dos 2568 sprites de karts:

    Resolução    Sem compressão    Com --dxt
    256x256      ~640 MB           ~160 MB
    128x128      ~160 MB           ~40 MB
    96x96        ~90 MB            ~23 MB

  * Use sempre o --dxt em pacotes HD.

  * O jogo é desenhado em 720p (mesmo com o console em 1080p). Acima de
    192x192, um sprite de kart quase não melhora na tela. O --reduzir-auto
    limita os karts, os menus e o HUD a esse tamanho ao empacotar, sem
    alterar os seus PNGs.

  * Se o tex.pak final tiver até uns 270 MB, ele é carregado inteiro na
    memória ao abrir o jogo, e não há leituras de disco nas corridas.


--------------------------------------------------------------------------
 PASSO 9 - EMPACOTE AS TEXTURAS (gera o tex.pak)
--------------------------------------------------------------------------

Se você editou texturas de várias pastas (o mais comum):

    py .\PACK_TEXTURES.py --pak --dxt

Se editou só uma pasta, por exemplo os karts:

    py .\PACK_TEXTURES.py --only karts --pak --dxt

O resultado é o arquivo tex\tex.pak.

Opções:

  --pak                    Cria um único arquivo tex.pak. Recomendado.

  --dxt                    Comprime as texturas no formato DXT, que o
                           Xbox 360 lê nativamente. Pak muito menor.
                           Recomendado para texturas HD. Em texturas
                           muito pequenas, pode perder um pouco de
                           qualidade.

  --dxt-compacto           Usar junto com --dxt. Deixa os sprites
                           (karts, itens, árvores) com metade do tamanho,
                           com um pouco menos de qualidade de cor. Use se
                           o tex.pak passar de uns 270 MB.

  --reduzir-auto           Limita os karts, o Lakitu, os menus e o HUD à
                           resolução útil em 720p. Perda de qualidade
                           quase imperceptível. Não altera os PNGs.
                           Recomendado para pacotes de resolução muito alta.

  --reduzir PASTA=TAMANHO  Reduz só uma pasta, em pixels ou porcentagem.
                           Ex.: --reduzir karts=192
                                --reduzir generated/course_player_selection=75%
                           Não altera os PNGs (para alterar os próprios
                           PNGs, use o HALVE_PNGS.py).

  --only PREFIXO           Empacota só uma pasta. Ex.: --only karts\bowser

  --out PASTA              Pasta de saída. Padrão: tex

  --max N                  Ignora imagens maiores que N pixels.
                           Padrão: 2048

Exemplo com várias opções:

    py .\PACK_TEXTURES.py --pak --dxt --dxt-compacto --reduzir-auto

  * Sem --pak, o script cria arquivos .tex soltos. Serve só para testes;
    para jogar, use sempre o --pak.

  * Empacote só as texturas que você realmente editou. Texturas não
    editadas viram cópias idênticas às originais: ocupam espaço sem
    melhorar nada.


--------------------------------------------------------------------------
 PASSO 10 - COMPILE O JOGO
--------------------------------------------------------------------------

Na pasta MKart360-Edit-Assets (a que tem o MK64.sln):

    powershell -ExecutionPolicy Bypass -File ".\PUBLIC_BUILD_XBOX360.ps1"


--------------------------------------------------------------------------
 PASSO 11 - PEGUE O XEX COMPILADO
--------------------------------------------------------------------------

O jogo compilado fica em:

    MKart360-Edit-Assets\MK64\Release\MK64.xex


--------------------------------------------------------------------------
 PASSO 12 - MONTE A PASTA DO JOGO NO CONSOLE
--------------------------------------------------------------------------

Crie uma pasta com qualquer nome (por exemplo, MK64) e coloque dentro
dela estes três arquivos:

    baserom.br.z64
    MK64.xex
    tex.pak

O tex.pak fica solto na pasta, ao lado do MK64.xex, e não dentro de uma
pasta tex.

Pronto: agora é só executar o MK64.xex no Xbox 360.
