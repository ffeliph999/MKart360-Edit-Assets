# COMO USAR

### 1. Instale o Visual Studio 2010 e o Xbox 360 XDK ou SDK

Eles são necessários para compilar o projeto para Xbox 360.

------------------------------------------------------------------------

### 2. Copie o Patch

Copie o patch para dentro da pasta `MKart360-Edit-Assets`.

------------------------------------------------------------------------

### 3. Adicione sua ROM

Renomeie sua ROM e coloque-a aqui:

`MKart360-Edit-Assets\mk64-master\baserom.br.z64`

Por exemplo, se a sua ROM se chama `Mario Kart 64 (USA).z64`, renomeie-a
para `baserom.br.z64`.

O jogo aceita a versão americana (USA) e a brasileira, e identifica qual é
pelo conteúdo, não pelo nome. A ROM precisa estar no formato `.z64`.

------------------------------------------------------------------------

### 4. Instale o Python

Você só precisa fazer isso uma vez.

```powershell
winget install Python.Python.3
```

Feche e abra o PowerShell novamente e verifique a instalação:

```powershell
py --version
```

Se aparecer algo semelhante a:

```text
Python 3.13.x
```

O Python foi instalado corretamente.

------------------------------------------------------------------------

### 5. Instale o Pillow

Você só precisa fazer isso uma vez.

```powershell
pip install pillow
```

------------------------------------------------------------------------

### 6. Configure as Ferramentas de Assets do Windows

Execute:

```powershell
powershell -ExecutionPolicy Bypass -File ".\xbox360\setup_windows_asset_tools.ps1" -SkipTorch
```

Isso prepara as ferramentas necessárias para trabalhar com os assets
e texturas do MK64 no Windows.

------------------------------------------------------------------------

### 7. Prepare a ROM e os Assets

Execute:

```powershell
py .\PUBLIC_PREPARE_MK64_ASSETS.py
```

Essa etapa prepara a ROM e os assets necessários para o fluxo de
extração e edição das texturas.

------------------------------------------------------------------------

### 8. Extraia as Texturas

Execute:

```powershell
py .\EXTRACT_MK64_TEXTURES.py
```

O script extrai as texturas e também prepara e sincroniza
automaticamente os manifestos necessários para o sistema de texturas HD.

**IMPORTANTE:**

Não é necessário copiar manualmente nenhum arquivo `.json` da pasta
`manifest_runtime` para `extracted_textures`.

O `EXTRACT_MK64_TEXTURES.py` faz essa sincronização automaticamente.

Se o script detectar que `extracted_textures` já foi extraído, ele entra
em modo de continuação e evita sobrescrever as texturas que você já editou.

------------------------------------------------------------------------

### 9. Edite as Texturas

As texturas extraídas serão colocadas em:

```text
extracted_textures
```

Abra os arquivos PNG e edite as texturas que desejar. Você pode
aumentar a resolução, redesenhar ou substituir completamente a
textura original.

Você também pode aumentar a resolução. Por exemplo, uma textura de
64×64 pode ser substituída por uma versão de 128×128.

**IMPORTANTE:**

Não renomeie os arquivos nem altere a estrutura das pastas.

O nome do arquivo e o caminho armazenados nos manifestos são usados para
associar a textura editada à textura original no jogo.

Depois de colocar ou alterar uma textura HD de fundo de menu, execute
novamente:

```powershell
py .\EXTRACT_MK64_TEXTURES.py
```

O script pode detectar as imagens HD já presentes e gerar as variantes
necessárias para os fundos coloridos dos menus.

------------------------------------------------------------------------

## LIMITES DE MEMÓRIA

O Xbox 360 possui 512 MB de memória compartilhada entre o sistema e os
gráficos, e o jogo já utiliza parte dessa memória.

Com todos os 2568 sprites de karts incluídos (duas metades por sprite),
o tamanho aproximado das texturas seria:

```text
Resolução   Sem compressão   Com --dxt
256×256     ~640 MB          ~160 MB
128×128     ~160 MB          ~40 MB
96×96       ~90 MB           ~23 MB
```

Com o `--dxt`, os karts em 256×256 ocupam o mesmo que em 128×128 sem
compressão. Por isso, use sempre o `--dxt` em pacotes HD.

O jogo é desenhado em 720p, mesmo com o console em 1080p. Nessa
resolução, um sprite de kart ocupa no máximo 192×192 pixels na tela;
acima disso, a diferença quase não aparece, mas a memória cresce. O
`--reduzir-auto` (veja o passo 10) limita os karts, os menus e o HUD a
esse tamanho na hora de empacotar, sem alterar os seus PNGs.

Quando o `tex.pak` final tem até uns 270 MB, ele é carregado inteiro na
memória ao abrir o jogo, e não há leituras de disco durante as corridas.

------------------------------------------------------------------------

### 10. Reconstrua as Texturas

Se você modificou apenas uma pasta de texturas, como os karts, execute:

```powershell
py .\PACK_TEXTURES.py --only karts --pak --dxt
```

Se você modificou texturas de várias pastas ou de todas as pastas de
texturas, execute:

```powershell
py .\PACK_TEXTURES.py --pak --dxt
```

O processo cria:

```text
tex\tex.pak
```

Esse é um único arquivo contendo as texturas empacotadas.

#### Opções disponíveis

`--pak`

Cria um único arquivo `tex.pak`. Recomendado.

`--dxt`

Gera um tex.pak comprimido utilizando o algorítmo DXT, (nativamente suportado pelo xbox360) (altamente recomendado para pacotes de textura em HD com texturas acima de 256x256 pixels)

`--dxt-compacto` (ex: `py .\PACK_TEXTURES.py --pak --dxt --dxt-compacto`)

Gera um tex.pak comprimido no **Modo compacto (`--dxt-compacto`).** Afeta só as texturas com transparência
"liga/desliga" (cada pixel totalmente visível ou totalmente transparente): os
sprites dos karts e personagens, itens, árvores. Por padrão elas usam DXT5 (4
cores por bloco 4×4 + transparência separada, 1 byte por pixel); no modo
compacto usam DXT1 (3 cores + "transparente", meio byte por pixel). isso deixa o PAK bem menor, mas a custo de qualidade, de cor nos sprites (cerca de 1,7 dB
  a menos nas medições): pode aparecer um leve granulado ou bordas um pouco mais
  claras, mais perceptíveis em sprites de baixa resolução. Use se seu tex.pak convencional exceder
270MB, pois paks maiores que isso impossibilitam de serem carregados direto na RAM, podendo causar
problemas de desempenho se o jogo estiver em um HD mecânico.

`--reduzir-auto` ou `--reduzir PASTA=TAMANHO` (ex: --reduzir karts=192), (ex2: --reduzir generated/course_player_selection=75%)

Reduz os sprites PNG dos karts, lakitu, menus e hud antes de empacota-los ao tex.pak limitando-os a resolução de renderização do jogo na tela (720p), diminuindo o tamanho do tex.pak para que ele possa caber na memoria, evitando problemas de desempenho, a perda de qualidade é quase imperceptivel, recomendado se você utilizou um pacote de texturas em HD de resolução muito alta. (nota: "--reduzir" não modifica os PNGs originais, apenas reduz uma copia que vai para o pak, se você quer reduzir os pngs originais, utilize HALVE_PNGS.py)

`--only PREFIX`

Limita o processo a uma pasta específica ou a um subconjunto.

Exemplo:

```powershell
--only karts\bowser
```

`--out FOLDER`

Define a pasta de saída.

Padrão:

```text
tex
```

`--max N`

Ignora imagens maiores que `N` pixels.

Padrão:

```text
2048
```

Sem `--pak`, o script cria arquivos `.tex` individuais dentro das
subpastas.

O formato `.pak` é recomendado para a versão final. Os arquivos `.tex`
individuais podem ser úteis para testes ou depuração.

A compactação DXT é recomendada para texturas muito grandes, acima de 256x256,
se o seu pacote de texturas tem no total mais de 200MB, é altamente recomendado
utilizar o --dxt, pois vai gerar um tex.pak muito menor, e vai ser menos pesado
para o xbox360 processar, mas atenção, texturas muito pequenas tendem a ficar
piores com o DXT, por que ele é um formato de compressão com perdas.

**IMPORTANTE:**

Sempre que possível, empacote apenas as texturas que você realmente
modificou.

Texturas que não foram editadas podem gerar arquivos que substituem
as texturas originais por cópias idênticas, sem proporcionar nenhuma
melhoria visual e ainda ocupando espaço adicional, podendo causar problemas de desempenho.

------------------------------------------------------------------------

### 11. Compile o Projeto para Xbox 360

Execute:

```powershell
powershell -ExecutionPolicy Bypass -File ".\PUBLIC_BUILD_XBOX360.ps1"
```

A etapa `PUBLIC_PREPARE_MK64_ASSETS.py` foi executada anteriormente,
antes da extração das texturas.

------------------------------------------------------------------------

### 12. Obtenha o XEX Compilado

Copie `MK64.xex` de:

```text
MKart360-Edit-Assets\MK64\Release\MK64.xex
```

------------------------------------------------------------------------

### 13. Crie a Pasta do Jogo

Crie uma pasta com qualquer nome que desejar. Por exemplo:

```text
MK64
```

Coloque os seguintes arquivos dentro dela:

```text
baserom.br.z64
MK64.xex
tex.pak
```

Pronto. Agora você está preparado para executar o jogo no Xbox 360.
