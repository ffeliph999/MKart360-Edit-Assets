==========================================================================
 MKart360 Edit Assets - HOW TO USE
==========================================================================

Follow the steps in order. Commands are on a line of their own, indented:
copy the whole line and paste it into PowerShell, inside the
MKart360-Edit-Assets\mk64-master folder (unless noted otherwise).

For detailed explanations, see README.md (in English) or LEIA-ME.md (in
Portuguese).


--------------------------------------------------------------------------
 STEP 1 - INSTALL VISUAL STUDIO 2010 AND THE XBOX 360 XDK
--------------------------------------------------------------------------

They are required to build the game for the Xbox 360.


--------------------------------------------------------------------------
 STEP 2 - ADD YOUR ROM
--------------------------------------------------------------------------

Rename your ROM to baserom.br.z64 and place it at:

    MKart360-Edit-Assets\mk64-master\baserom.br.z64

Example: if your ROM is named "Mario Kart 64 (USA).z64", rename it to
baserom.br.z64.

The game accepts the American (USA) and Brazilian versions, and tells
which one it is by its content, not by its name. The ROM must be in
.z64 format.


--------------------------------------------------------------------------
 STEP 3 - INSTALL PYTHON (only once)
--------------------------------------------------------------------------

    winget install Python.Python.3

Close and reopen PowerShell, then check the installation:

    py --version

If you see something like "Python 3.13.x", everything is fine.


--------------------------------------------------------------------------
 STEP 4 - INSTALL PILLOW (only once)
--------------------------------------------------------------------------

    pip install pillow


--------------------------------------------------------------------------
 STEP 5 - SET UP THE ASSET TOOLS
--------------------------------------------------------------------------

    powershell -ExecutionPolicy Bypass -File ".\xbox360\setup_windows_asset_tools.ps1" -SkipTorch

Prepares the tools to work with the assets and textures.


--------------------------------------------------------------------------
 STEP 6 - PREPARE THE ROM AND THE ASSETS
--------------------------------------------------------------------------

    py .\PUBLIC_PREPARE_MK64_ASSETS.py


--------------------------------------------------------------------------
 STEP 7 - EXTRACT THE TEXTURES
--------------------------------------------------------------------------

    py .\EXTRACT_MK64_TEXTURES.py

The textures go to the extracted_textures folder, and the manifests
(.json) are prepared automatically. There is no need to copy anything
from the manifest_runtime folder.

If you run it again, the textures you already edited are not
overwritten.


--------------------------------------------------------------------------
 STEP 8 - EDIT THE TEXTURES
--------------------------------------------------------------------------

Open the PNGs in extracted_textures and edit the ones you want: redraw,
replace or increase the resolution (e.g. from 64x64 to 128x128).

  * Do not rename the files or change the folder structure: the name and
    the path link each PNG to the game's original texture.

  * After adding or changing an HD menu background texture, run step 7
    again. The extractor generates the colored versions of the
    backgrounds.


--------------------------------------------------------------------------
 MEMORY LIMITS (read before step 9)
--------------------------------------------------------------------------

The Xbox 360 has 512 MB of memory, shared with the game. Approximate
size of the 2568 kart sprites:

    Resolution   Uncompressed      With --dxt
    256x256      ~640 MB           ~160 MB
    128x128      ~160 MB           ~40 MB
    96x96        ~90 MB            ~23 MB

  * Always use --dxt for HD packs.

  * The game is rendered at 720p (even with the console set to 1080p).
    Above 192x192, a kart sprite barely improves on screen. --reduzir-auto
    caps karts, menus and HUD at that size at pack time, without changing
    your PNGs.

  * If the final tex.pak is up to about 270 MB, it is loaded entirely
    into memory when the game starts, and there are no disk reads during
    races.


--------------------------------------------------------------------------
 STEP 9 - PACK THE TEXTURES (builds tex.pak)
--------------------------------------------------------------------------

If you edited textures in several folders (the most common case):

    py .\PACK_TEXTURES.py --pak --dxt

If you only edited one folder, for example the karts:

    py .\PACK_TEXTURES.py --only karts --pak --dxt

The result is the tex\tex.pak file.

Options:

  --pak                    Creates a single tex.pak file. Recommended.

  --dxt                    Compresses the textures in DXT format, which
                           the Xbox 360 reads natively. Much smaller pack.
                           Recommended for HD textures. Very small
                           textures may lose a little quality.

  --dxt-compacto           Use together with --dxt. Makes sprites (karts,
                           items, trees) half the size, with slightly
                           lower color quality. Use it if tex.pak goes
                           over about 270 MB.

  --reduzir-auto           Caps karts, Lakitu, menus and HUD at the useful
                           resolution for 720p. Almost imperceptible
                           quality loss. Does not change the PNGs.
                           Recommended for very high resolution packs.

  --reduzir PASTA=TAMANHO  Reduces only one folder, in pixels or percent.
                           E.g.: --reduzir karts=192
                                 --reduzir generated/course_player_selection=75%
                           Does not change the PNGs (to change the PNGs
                           themselves, use HALVE_PNGS.py).

  --only PREFIX            Packs only one folder. E.g.: --only karts\bowser

  --out FOLDER             Output folder. Default: tex

  --max N                  Skips images larger than N pixels.
                           Default: 2048

Example with several options:

    py .\PACK_TEXTURES.py --pak --dxt --dxt-compacto --reduzir-auto

  * Without --pak, the script creates loose .tex files. They are only for
    testing; to play, always use --pak.

  * Pack only the textures you actually edited. Unedited textures become
    copies identical to the originals: they take up space without
    improving anything.


--------------------------------------------------------------------------
 STEP 10 - BUILD THE GAME
--------------------------------------------------------------------------

In the MKart360-Edit-Assets folder (the one with MK64.sln):

    powershell -ExecutionPolicy Bypass -File ".\PUBLIC_BUILD_XBOX360.ps1"


--------------------------------------------------------------------------
 STEP 11 - GET THE COMPILED XEX
--------------------------------------------------------------------------

The compiled game is at:

    MKart360-Edit-Assets\MK64\Release\MK64.xex


--------------------------------------------------------------------------
 STEP 12 - SET UP THE GAME FOLDER ON THE CONSOLE
--------------------------------------------------------------------------

Create a folder with any name (for example, MK64) and put these three
files inside it:

    baserom.br.z64
    MK64.xex
    tex.pak

tex.pak goes loose in the folder, next to MK64.xex, and not inside a tex
folder.

Done: now just run MK64.xex on the Xbox 360.
