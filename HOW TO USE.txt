# HOW TO USE

### 1. Install Visual Studio 2010 and the Xbox 360 XDK or SDK

These are required to compile the project for Xbox 360.

------------------------------------------------------------------------

### 2. Copy the Patch

Copy the patch into the `MKart360-Universal` folder.

------------------------------------------------------------------------

### 3. Add Your ROM

Rename your ROM and place it here:

`MKart360-Universal\mk64-master\baserom.br.z64`

For example:

------------------------------------------------------------------------

### 4. Install Python

You only need to do this once.

``` powershell
winget install Python.Python.3
```

Close and reopen PowerShell, then check the installation:

``` powershell
py --version
```

If you see something similar to:

``` text
Python 3.13.x
```

Python is installed correctly.

------------------------------------------------------------------------

### 5. Install Pillow

You only need to do this once.

``` powershell
pip install pillow
```

------------------------------------------------------------------------

### 6. Set Up the Windows Asset Tools

Run:

``` powershell
powershell -ExecutionPolicy Bypass -File ".\xbox360\setup_windows_asset_tools.ps1" -SkipTorch
```

This prepares the tools needed to work with the MK64 assets and textures
on Windows.

------------------------------------------------------------------------

### 7. Prepare the ROM and Assets

Run:

``` powershell
py .\PUBLIC_PREPARE_MK64_ASSETS.py
```

------------------------------------------------------------------------

### 8. Extract the Textures

Run:

``` powershell
py .\EXTRACT_MK64_TEXTURES.py
```

------------------------------------------------------------------------

### 9. Edit the Textures

The extracted textures will be placed in:

``` text
extracted_textures
```

Open the PNG files and edit any textures you want. You can upscale them,
redraw them, or completely replace the original texture.

You can also increase the resolution. For example, a 64×64 texture can
be replaced with a 128×128 version.

**IMPORTANT:**

Do not rename the files or change the folder structure.

The file name and path stored in the manifest are used to match the
edited texture with the original texture in the game.

------------------------------------------------------------------------

## MEMORY LIMITS

The Xbox 360 has 512 MB of shared memory for the system and graphics,
and the game already uses part of that memory.

With all 2568 sprites included, using two files per sprite, the
approximate raw RGBA32 image sizes would be:

``` text
256×256  →  ~640 MB
128×128  →  ~160 MB
96×96    →  ~90 MB
```

These are estimates of the raw image data and do not represent the
actual final memory usage of the game.

Higher texture resolutions require more memory and increase loading
costs.

Because of this, 128×128 can be a good option for improving image
quality without using as much memory as 256×256.

------------------------------------------------------------------------

## REDUCING TEXTURE RESOLUTION

If you want to reduce the resolution of your edited PNGs by half, place:

``` text
HALVE_PNGS.py
```

in the main project folder and run:

``` powershell
py .\HALVE_PNGS.py --recursive
```

This only previews the changes and does not modify the files.

To apply the changes:

``` powershell
py .\HALVE_PNGS.py --apply --recursive
```

To create a backup of the original files before making the changes:

``` powershell
py .\HALVE_PNGS.py --apply --recursive --backup
```

The original files will be kept with the following extension:

``` text
*.orig.png
```

------------------------------------------------------------------------

### 10. Copy the Runtime Manifests

The HD texture system uses two runtime manifests that must be copied
from:

``` text
manifest_runtime
```

to:

``` text
extracted_textures
```

Copy these two files:

``` text
manifest_runtime\texture_tkmk00_runtime_manifest.json
manifest_runtime\texture_tkmk00_names_runtime_manifest.json
```

into:

``` text
extracted_textures\texture_tkmk00_runtime_manifest.json
extracted_textures\texture_tkmk00_names_runtime_manifest.json
```

You can do this from PowerShell with:

``` powershell
Copy-Item ".\manifest_runtime\texture_tkmk00_runtime_manifest.json" ".\extracted_textures\texture_tkmk00_runtime_manifest.json" -Force
Copy-Item ".\manifest_runtime\texture_tkmk00_names_runtime_manifest.json" ".\extracted_textures\texture_tkmk00_names_runtime_manifest.json" -Force
```

**IMPORTANT:**

Do this after editing the textures and **before** running
`PACK_TEXTURES.py`.

The manifests provide the runtime texture information required by the
packing process. They replace the old `PATCH_HD_TEXTURES.py` step in the
current workflow.

------------------------------------------------------------------------

### 11. Rebuild the Textures

If you only modified one texture folder, such as the karts, run:

``` powershell
py .\PACK_TEXTURES.py --only karts --pak
```

If you modified textures from multiple folders or all texture folders,
run:

``` powershell
py .\PACK_TEXTURES.py --pak
```

The process creates:

``` text
tex\tex.pak
```

This is a single file containing the packed textures.

#### Available Options

`--pak`

Creates a single `tex.pak` file. Recommended.

`--only PREFIX`

Limits the process to a specific folder or subset.

Example:

``` powershell
--only karts\bowser
```

`--out FOLDER`

Sets the output folder.

Default:

``` text
tex
```

`--max N`

Skips images larger than `N` pixels.

Default:

``` text
2048
```

Without `--pak`, the script creates individual `.tex` files inside
subfolders.

The `.pak` format is recommended for the final version. Individual
`.tex` files can be useful for testing or debugging.

**IMPORTANT:**

Whenever possible, only pack the textures you actually modified.
Unedited textures can generate files that replace the original textures
with identical copies, providing no visual improvement while taking up
additional space.

------------------------------------------------------------------------

### 12. Compile the Project for Xbox 360

Run:

``` powershell
powershell -ExecutionPolicy Bypass -File ".\PUBLIC_BUILD_XBOX360.ps1"
```

------------------------------------------------------------------------

### 13. Get the Compiled XEX

Copy `MK64.xex` from:

``` text
MKart360-Universal\MK64\Release\MK64.xex
```

------------------------------------------------------------------------

### 14. Create the Game Folder

Create a folder with any name you want. For example:

``` text
MK64
```

Place the following files inside it:

``` text
baserom.br.z64
MK64.xex
tex.pak
```

That's it. You're ready to run the game on Xbox 360.
